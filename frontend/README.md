# Auralytics Frontend

Autonomous Influencer Marketing platform UI.

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- React Router
- Recharts
- Lucide Icons

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Demo Flow

1. Landing → Sign in
2. Onboarding wizard (first visit)
3. Dashboard → Create Campaign
4. Campaign Command Center
5. Influencer Discovery → Shortlist
6. Outreach → Approvals
7. Contracts → Analytics → Optimization
8. AI Agent Center → Reports

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run preview` — preview production build
